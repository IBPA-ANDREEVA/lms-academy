# Visual Reference Register

The reference folders are intentionally empty until screenshots/approved assets are supplied. Do not treat example names as existing files.

## How to document a reference
- ID and local screenshot path or Figma frame URL
- Status: `approved` / `rejected` / `exploratory`
- Applicable screen/component
- **Borrow:** exact visual relationship (e.g., hero 45% text / 55% image, large cropping)
- **Do not borrow:** colors, fonts, effects or composition patterns that conflict with `DIRECTION.md`
- Mobile/Russian caveats
- Reviewer/date
