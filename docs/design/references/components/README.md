# Component visual reference assets

No component-specific images or visual approvals are seeded automatically. See the [component registry](../../components/INDEX.md); every initial record explicitly reports **MISSING REFERENCE**.

Upload through `/dev/components`. Each component gets a stable-ID folder containing immutable PNG/JPEG/WebP assets and generated readable Markdown. Canonical explanations and approval metadata live in `../../components/registry/<component-id>.json`. Do not hand-edit the generated Markdown. Removed or replaced images remain recoverable; the active global index is generated from canonical records. Images are design evidence, not production assets with inferred licensing.
