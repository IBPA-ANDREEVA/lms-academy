## Icon Creation Workflow

- Approved SVG icons are the source of truth.
- Reuse existing icons before creating new ones.
- Major branded icons must follow approved Figma references.
- Codex may create new SVG icons only within the
  established geometric icon system.
- New branded icons require visual review before approval.
- Generic UI icons may use Lucide with consistent styling.
- Do not substitute emoji or raster images for SVG icons.
- Store reusable icon components in shared/ui/icons.
