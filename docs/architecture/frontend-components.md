## Preserved layout and appearance decisions

PageContainer caps the **inner content** at 1920px wide, 1440px content, or 760px reading; outer gutters are `clamp(20px, 4.1667vw, 96px)`. FullBleed fills its parent without gutters, not the viewport from inside a constrained ancestor. It owns no vertical spacing, background or grid. These values supersede the earlier generic 1320px candidate.

Button appearance and semantic intent are separate. NeoBrutalist has a 2px border and hard offset shadow; Cut has a skewed parallelogram outline, detached trailing slash, upright content and a blush hover; Minimal has modest rounding and a restrained surface highlight. Target heights: 44/48/56px. Disabled/loading block activation; busy keeps label and geometry. CSS motion is suppressed under reduced motion. The header's pill account action is a scoped reference-specific class, not a new duplicated button.

The current owner request supersedes the earlier pale menu trigger and mobile dialog design. The homepage top state is full width with white ink, a dark translucent backing, a right-side plum diagonal and a plum hairline. After 48px of scroll, the same instance eases into an inset white rounded bar with dark ink, smaller internal spacing and a restrained shadow. GSAP animates the progress and ink variables within the existing scroll-state lifecycle; reduced motion switches immediately. The fixed header slot maintains hero geometry while the bar changes size. Other routes use the compact filled state from the start. The shared Button supplies the plum sign-in pill; the inspected line cart SVG remains an icon mask and is disabled until an actual cart link is supplied. No count is fabricated.

The four primary destinations (academy, learning, reviews, contact) are centered between brand and actions. Preview badges are omitted from the header; account and cart are present only as right-side controls. At 760px and below, brand and actions occupy the first row and navigation moves into a shorter, horizontally scrollable second row. The disclosure opens below this rail without clipping; native summary keyboard behavior, Escape, outside click and navigation closure remain available. There is no hamburger or hidden destination. The header's `Войти` button opens the UI-only identity modal and receives focus after close. Unavailable entries still have no fabricated href. Tests may supply fixture links without publishing them.

PublicFooter borrows charcoal contrast, restrained plum accents, column hierarchy and thin separators; it does not copy the mockup logo, social accounts, newsletter, EN or invented legal copy. Mobile groups remain directly visible (the source allows optional disclosure). Compact shares the same implementation and legal content. Four approved legal destinations and a signed-off certificate disclaimer are release blockers; the current shell displays their titles as unavailable «Скоро» entries without fabricated text or broken links.

Generic auth wrappers and redirect utilities were not extracted: no identity flow exists yet. Reuse PasswordField and FormControls when those flows are implemented. Client UI is never an authorization boundary.
