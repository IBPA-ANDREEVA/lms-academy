## Preserved definitions and reference constraints

PageContainer inner maximums: wide 1920px, content 1440px, reading 760px; gutters `clamp(20px,4.1667vw,96px)`. FullBleed fills its parent, not viewport escape. Default geometry has no vertical spacing/background/grid; opt-in `reveal` adds owned entry motion.

Button target heights are 44/48/56px. NeoBrutalist retains outline/offset shadow; Cut retains upright label, parallelogram frame and detached slash with reduced-motion-safe hover. Minimal remains restrained. Header pill is a scoped exception, not a fourth family. Preserve owner-edited definitions and D-014–D-017 reference scope; no complete browser implementation has human visual approval.

PublicHeader overlays home hero and catalogs; after 48px scroll its surface contracts. Mobile ≤760px uses a two-row rail, no hamburger/modal menu. HOME-06–09 secondary nav attaches to the header **bar** bottom, which differs from the entire header box by 10px at desktop. Footer unavailable entries suppress visible badges under the latest recorded owner direction; do not document them as functional legal/account links.

The component preview intentionally showcases nine families in rendered order recorded in [sections](frontend-sections.md). It is not exhaustive coverage of all product components: PurchasePanel, PreviewPlayer, detail anatomy and AuthModal are not separate preview sections. Auth is reachable from root header; real media/offer-state variants remain unverified. Keep the preview synchronized when a shared API changes.

Authoritative prices/auth/access/refunds/completion stay with future `src/server` contracts (ADR-0002). Source business domains, persistence and service integrations are absent today. Public Site owns presentation, Catalog owns approved published content/offers, Commerce owns cart/checkout calculations and payment, Identity owns sessions, Administration owns approval/publication workflows; policy-publication domain ownership remains a SALE002 preparation decision. Existing frontend files are not migrated to those server folders.
