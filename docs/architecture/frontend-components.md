## Preserved layout and appearance decisions

PageContainer caps the **inner content** at 1920px wide, 1440px content, or 760px reading; outer gutters are `clamp(20px, 4.1667vw, 96px)`. FullBleed fills its parent without gutters, not the viewport from inside a constrained ancestor. It owns no vertical spacing, background or grid. These values supersede the earlier generic 1320px candidate.

Button appearance and semantic intent are separate. NeoBrutalist has a 2px border and hard offset shadow; Cut has a skewed parallelogram outline, detached trailing slash, upright content and a blush hover; Minimal has modest rounding and a restrained surface highlight. Target heights: 44/48/56px. Disabled/loading block activation; busy keeps label and geometry. CSS motion is suppressed under reduced motion. The header's pill account action is a scoped reference-specific class, not a new duplicated button.

PublicHeader borrows the supplied image's white rounded bar, restrained shadow, wordmark alignment, dropdown, plum account action, cart and pale circular menu trigger. Full desktop above 1024px; tablet through 1024px keeps three navigation items (two below 921px); 768px and below moves navigation into the dialog. All links remain available in that dialog. Native dialog plus explicit Tab wrapping supplies focus containment, Escape and inert background; closing restores trigger focus. Desktop disclosure supports keyboard, Escape, outside click and navigation closure. No hover-only navigation. Existing line SVGs are used as CSS masks in currentColor without changing source artwork.

The updated HOME-02 reference scopes a transparent, integrated PublicHeader to `/` through the hero marker. The same sticky instance transitions to a rounded white inner bar after 48px of page scroll (64px desktop / 60px mobile, with 16px / 10px side gutters), with dark text, modest shadow, adjusted internal spacing and no document reflow. The transition reverses on return to the top and is disabled under reduced motion. No duplicate header or new props were added. The `/preview/components` example and other routes keep the existing white rounded treatment. Desktop menu access uses the existing dialog behavior on the homepage.

Reference content is conditional: packages, EN and Start in USA are not released by an image. The only public product route is `/` (a separate `/preview/components` review utility is available). The owner requested populated preview navigation: working home anchors for academy, learning, reviews and contact; packages/USA/reviews carry preview labels; account/cart and unavailable legal destinations are disabled entries without href. The mobile dialog shows learning sublinks directly, contains focus, locks body scroll and closes on anchor selection. No production links point at nonexistent screens. Tests may supply fixture links without publishing them.

PublicFooter borrows charcoal contrast, restrained plum accents, column hierarchy and thin separators; it does not copy the mockup logo, social accounts, newsletter, EN or invented legal copy. Mobile groups remain directly visible (the source allows optional disclosure). Compact shares the same implementation and legal content. Four approved legal destinations and a signed-off certificate disclaimer are release blockers; the current shell displays their titles as unavailable «Скоро» entries without fabricated text or broken links.

Generic auth wrappers and redirect utilities were not extracted: no identity flow exists yet. Reuse PasswordField and FormControls when those flows are implemented. Client UI is never an authorization boundary.
