# Local fonts

Unmodified variable TTFs from Google Fonts, embedded through `next/font/local` in `src/app/layout.tsx`.

- Manrope: preserved from the retired planning editor; [upstream source](https://github.com/google/fonts/tree/main/ofl/manrope), `OFL-Manrope.txt`, weight axis 200–800.
- Unbounded: downloaded 2026-10-28 from [upstream source](https://github.com/google/fonts/tree/main/ofl/unbounded), `OFL-Unbounded.txt`, weight axis 200–900.

Both include Cyrillic and their original copyright/license. Keep licenses with redistributed font files. No browser requests to Google Fonts. Display glyph rendering and layout still require per-screen verification.
